# 🔐 TrustVault

**Secure Document Sharing with a Verifiable Audit Trail**

TrustVault is a web-based document management and sharing application designed to help users securely upload, access, download, and share documents while maintaining an audit trail of important actions.

## ✨ Features

- 🔑 User Authentication
- 📁 Secure Document Upload and Download
- 🗑️ Document Deletion
- 👥 Document Sharing and Permission Management
- 🔒 Grant and Revoke Access Permissions
- 📋 Audit Trail for Tracking Important Actions
- 🛡️ Backend API Security

## 🛠️ Tech Stack

**Frontend:** React, Vite  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JSON Web Tokens (JWT)  
**Security:** Helmet, CORS, Rate Limiting, Password Hashing

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/23jr1a0561-cyber/TrustVault.git
cd TrustVault
```

### 2. Install backend dependencies

```bash
cd backend
npm install
```

Configure the required environment variables in a `.env` file before starting the backend.

### 3. Install frontend dependencies

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Configure the frontend API URL and Mongo
